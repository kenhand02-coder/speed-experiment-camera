# 速さの実験カメラ

「起動.cmd」をダブルクリックして起動します。起動中は黒いウィンドウを開いておいてください。ブラウザーが先に開いて接続できなかった場合は再読み込みしてください。Node.js が必要です。このPCでは Codex 同梱の Node.js も利用できます。

1. カメラを起動し、ブラウザーのカメラ使用を許可します。
2. 録画開始・終了を押します。経過時間は小数第2位まで表示し、保存動画にも焼き込みます。
3. 撮影映像を一時停止して、開始点・終了点を選択します。
4. 移動距離を m または cm で入力すると、平均の速さを m/s で表示します。
5. 「動画を保存」で録画を保存します。ページを閉じると未保存の映像は失われます。

カメラ利用には localhost または HTTPS が必要です。HTML ファイルを直接開くのではなく、起動スクリプトを使ってください。スマートフォンから使うには HTTPS での公開が必要です。

表示が0.01秒単位でも、撮影の精度が0.01秒になるわけではありません。録画は最大30fpsを指定しており、端末負荷によってフレーム落ちすることもあります。±0.01秒操作は時刻を移動する機能で、厳密なコマ送りではありません。時刻の選択値は0.01秒に丸めて計算します。

音声は録音せず、外部サーバーに映像を送信しません。ブラウザーの録画形式に応じて WebM または MP4 で保存します。撮影中にタブを切り替える・画面を非表示にすると録画を停止します。長時間録画は端末のメモリを消費するため、短い実験ごとに保存してください。
